# EXTINCTION2

Versión 3D en primera persona de EXTINCTION, hecha con HTML, CSS, JavaScript y Three.js.

Características principales:
- Cámara FPS con Pointer Lock.
- Arma visible al frente con retroceso y fogonazo.
- Zombis 3D construidos con geometrías, materiales y animación procedural.
- Cinco escenarios: Dead City, Blackout Hospital, Toxic District, The Underground y Ground Zero.
- Tipos de infectado: común, corredor, brute, screamer, stalker, volt y Subject Zero.
- Disparos por raycast, headshots y combos.
- Kits médicos, munición, monedas, armadura y ADN flotantes.
- Linterna táctica, mutaciones temporales y extracción.
- Refugios, barricadas, torretas y trampas eléctricas.

## Ejecutar

Por usar módulos ES y Three.js desde CDN, abre el proyecto con un servidor local. En VS Code puedes usar Live Server y abrir `index.html`.

## Controles

- WASD: moverse
- Mouse: mirar
- Clic izquierdo: disparar
- R: recargar
- H: usar kit médico
- L: linterna
- Q: activar mutación ADN
- E: interactuar / iniciar extracción
- B: construir barricada
- T: construir torreta
- G: construir trampa eléctrica
- ESC: liberar el mouse / pausar
